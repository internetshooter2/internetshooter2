# 🧟‍♂️ Severed Veil

**Extraction PvP shooter** with Tarkov-level loot anxiety, *zombie panic attacks*, and **deployable cover** that makes you feel like a tactical genius.

> "Get in, loot fast, shoot first, cry later."

---

## ⚔️ What is this?

**Severed Veil** is a hardcore PvPvE extraction shooter where:
- Players fight to survive against both each other and infected enemies
- Quests, crafting, looting, and deployable cover keep things tactical
- Every raid is a high-stakes choice between greed and survival

---

## 🛠️ Built With

- **C#** – Core game logic in Unity
- **HTML + JavaScript** – UI, web integrations
- **Python** – Backend experiments & scripting
- **Photon PUN2** – Multiplayer setup
- **Frutiger Aero aesthetic** – Because purple is 🔛🔝
